# İlim Vakti – İslami Pomodoro

Ders çalışırken kullanılan İslami temalı bir pomodoro sayacı.

- Başlarken Besmele ve "Rabbi zidni ilma" duası
- Çalışma ve mola süresini kendin belirlersin
- Molada hedefli zikir sayacı (tesbih)
- Her tamamlanan oturumla yeni şehir açılır: Kâbe → Medine → Filistin → Şam → Doğu Türkistan

Kullanmak için `index.html` dosyasını tarayıcıda aç ya da GitHub Pages bağlantısını kullan.
